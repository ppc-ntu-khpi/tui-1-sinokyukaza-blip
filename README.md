# UI Lab 1 — TUI with Jexer

## Description

This project demonstrates a text user interface (TUI)
created using the Jexer library.

The application allows:

* entering customer number;
* displaying customer information;
* viewing account details.

The project uses classes from previous Banking labs:

* Bank
* Customer
* Account

## Technologies

* Java
* Jexer
* Swing backend
